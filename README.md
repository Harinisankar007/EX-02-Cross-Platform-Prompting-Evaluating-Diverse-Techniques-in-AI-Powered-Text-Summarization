# EX-02-Cross-Platform-Prompting-Evaluating-Diverse-Techniques-in-AI-Powered-Text-Summarization

## AIM
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: text summarization.

## Scenario:
You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience

# AI Tools Used:
* ChatGPT
* Claude AI 

## Algorithm
Step 1: Select a specific application, such as AI-based student performance prediction.

Step 2: Choose AI platforms such as ChatGPT and Gemini.

Step 3: Prepare five different prompt structures:
- Basic Prompt
- Role Prompt
- Context Prompt
- Constraint Prompt
- Output Format Prompt
Step 4: Enter the same prompts into both AI platforms.

Step 5: Generate responses for each prompting technique.

Step 6: Collect and save the generated outputs from both platforms.

Step 7: Evaluate the responses based on accuracy, coherence, simplicity, speed, and user experience.

Step 8: Compare the responses generated by ChatGPT and Claude AI.

Step 9: Identify the most effective prompting technique and AI platform.

Step 10: Document the observations, comparison, and final results.

# EXPERIMENT:
## Designing Different Prompt Structures for AI-Based Student Performance Prediction
## Selected Application:

### 1. Basic Prompt
Prompt:
Summarize the given text.

### 2. Role Prompt
Prompt:
Act as an expert content summarizer. Summarize the given text in a clear and simple way.

### 3. Context Prompt
Prompt:
Act as an expert content summarizer. The text is from an educational article intended for college students. Summarize the important concepts so that students can understand the main ideas easily.

### 4. Constraint Prompt
Prompt:
Act as an expert content summarizer. The text is from an educational article intended for college students. Summarize the important concepts in 100–150 words. Include only the key ideas, avoid unnecessary details, and use simple English.

### 5. Output Format Prompt – Final Prompt
Prompt:
Act as an expert academic content summarizer. Summarize the given educational text for college students. Identify the main ideas, important concepts, and key conclusions. Keep the summary between 100–150 words, use simple and clear English, avoid repetition and unnecessary details, and do not add information that is not present in the original text. Present the output with a short title followed by the summary in one paragraph.

### Ranking Explanation
The Output Format Prompt ranks first because it combines several prompt elements, including role, context, constraints, content requirements, and output structure. The Constraint Prompt ranks second because it provides strong control over the length and content. The Context Prompt improves audience relevance, while the Role Prompt mainly improves the style and perspective. The Basic Prompt ranks last because it provides very little guidance.

### Most Effective Prompt Type
Output Format Prompt
The Output Format Prompt was the most effective prompt type for both ChatGPT and Claude AI. It provided detailed instructions about what to summarize, who the summary was for, the required word limit, the writing style, the information to include, and how the final answer should be presented.

Because of these instructions, the final responses were more focused, consistent, structured, and suitable for college students.

## Conclusion
The experiment shows that prompt structure has a significant effect on the quality of AI-generated summaries. Both ChatGPT and Claude AI performed well when given clear instructions. The Basic Prompt produced a general summary, while adding a role, context, and constraints progressively improved the output. The Output Format Prompt produced the most controlled and structured result because it combined all the important prompt elements. Overall, both ChatGPT and Claude AI demonstrated strong performance, with the final prompt providing the most effective approach for academic text summariz

## Result
The experiment was successfully conducted by designing and testing five different prompt structures (Basic, Role, Context, Constraint, and Output Format) for the text summarization application using ChatGPT and Claude AI. The outputs from both AI platforms were compared based on clarity, accuracy, simplicity, instruction following, word-limit control, and formatting. The results showed that the **Output Format Prompt was the most effective technique**, as it generated well-structured, clear, and focused summaries. Overall, both ChatGPT and Claude AI demonstrated effective text summarization capabilities, with improved output quality when more specific and detailed prompts were provided.
